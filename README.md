# LedgerLine-Piano

## What it is
LedgerLine lets piano teachers see their students’ real practice: ordered repertoire, practice logs, a dashboard and a weekly progress card.

## Stack
Flask + Jinja, vanilla JS, Supabase Postgres (psycopg 3), Plotly, Render, Vercel.
